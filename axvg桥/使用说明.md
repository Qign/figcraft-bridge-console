# Axure → FigCraft 反向桥 使用说明

把 Axure 里的元件搬到 FigCraft 的常驻热键桥。与 `D:\AI\FigCraft\axure桥`（FigCraft → Axure 正向桥）方向相反，两者可同时开、互不干扰。

| 项目 | 值 |
|---|---|
| 导入热键 | `Ctrl+Alt+V` |
| 暂停/恢复热键 | `Ctrl+Alt+S` |
| FigCraft 控制端口 | 47900（正向桥共用同一端口） |
| 日志 | `%TEMP%\axure2figcraft\bridge.log` |
| 暂停标志 | `%TEMP%\axure2figcraft\paused.flag` |
| 最近一次导入的原始内容 | `%TEMP%\axure2figcraft\last_axvg.txt` |

---

## 一、前提：FigCraft 必须带控制端口启动

反向桥通过 FigCraft 的控制通道写入节点，所以 FigCraft 进程必须带 `--control 47900`。

- 已经在用「启动FigCraft(带转换桥).lnk」→ 满足条件，不用管。
- 如果 FigCraft 是双击图标或从最近文件打开的（没有 `--control`）→ 端口 47900 不通，按热键只会弹提示。
  处理：先保存当前文档，关掉 FigCraft，再用 `D:\AI\FigCraft\axure桥\启动FigCraft(带转换桥).lnk` 打开。
  或者直接双击本目录的 `一键启用(FigCraft+反向桥).bat`，它会检测端口、没开就顺手启动。

## 二、启用

三种方式，任选其一（效果相同）：

1. **双击 `一键启用(FigCraft+反向桥).bat`** —— 最省事，顺带确保 FigCraft 带端口启动。
2. **双击 `启用反向桥.bat`** —— 只启桥，不动 FigCraft。
3. 命令行：`cd /d D:\AI\FigCraft\axvg桥 && C:\Python313\python.exe bridge_ctl.py start`

启用后桥在后台静默运行（`pythonw.exe`，无窗口、无托盘）。重复启用不会开第二个实例，会提示"已在运行"并确保是启用状态。

确认是否生效：双击 `查看状态.bat`，应显示

```
反向桥：运行中（PID xxxx）—— 热键有效
FigCraft：已连接控制端口 47900
```

## 三、日常使用

1. Axure 里选中元件 → `Ctrl+C`（或右键「复制为 Axure Cloud」）。
   注意：普通 `Ctrl+C` 复制出来的内容如果首行不是 `// axvg`，桥会提示"剪贴板里不是 Axure Cloud 的复制内容"。
2. 切到 FigCraft，按 `Ctrl+Alt+V`。
3. 右下角弹出统计，例如「已导入 1 组、27 元件、11 矢量」。
4. 新内容会整组落在当前页面**已有内容的最右侧**（留 60px 间隙），不会盖住现有稿子。落进来就是普通节点，可继续编辑。

## 四、临时避让（不退出程序）

按 `Ctrl+Alt+S` → 桥暂停，热键不再导入，进程仍在。
再按一次 `Ctrl+Alt+S` → 恢复。

适合场景：要临时把 `Ctrl+Alt+V` 让给别的软件、或不想被误触发。
暂停状态会写进 flag 文件，重启桥后仍然保持，`启用反向桥.bat` 会把它清成启用状态。

## 五、停用

1. **双击 `停用反向桥.bat`**（推荐）
2. 或命令行：`C:\Python313\python.exe bridge_ctl.py stop`

停用后：`Ctrl+Alt+V` / `Ctrl+Alt+S` 都不会有反应，进程彻底退出，热键释放。
停用不影响 FigCraft，也不动已经导入的稿子。

> 只匹配命令行含 `axure_to_figcraft_bridge.py` 的 python 进程，排除 `--toast` 提示子进程。
> 不会误杀机器上其它 Python 程序，也不会影响正向桥（`figcraft_axure_bridge.py`）。

## 六、排错

| 现象 | 原因 / 处理 |
|---|---|
| 按热键没反应、也没提示 | 桥没在运行 → 双击 `启用反向桥.bat`；或已暂停 → 查 `查看状态.bat` |
| 提示"FigCraft 控制端口未开" | FigCraft 没带 `--control 47900` 启动 → 见「一、前提」 |
| 提示"热键被其它程序占用" | 换一组键：`调试运行.bat` 改成 `python axure_to_figcraft_bridge.py --hotkey ctrl+alt+b`；或先 `停用反向桥.bat` 清干净再启 |
| 提示"剪贴板里不是 Axure Cloud 的复制内容" | 用的是普通 Ctrl+C，Axure 老版本需要右键「复制为 Axure Cloud」 |
| 提示"引用了尚未创建的节点" | 转换脚本与桥版本不一致 → 确认 `axvg_to_figcraft.py` 与桥同目录 |
| 导入成功但样式不对 | 看 `%TEMP%\axure2figcraft\bridge.log`，把失败条目发我 |

前台看报错：先 `停用反向桥.bat`，再双击 `调试运行.bat`（有黑窗口，报错直接可见）。

## 七、不能转的内容

动态面板、母版实例、Repeater、交互用例与动效、样式库引用 —— 这些在 Axure 里没有等价的 FigCraft 表达，转换时按静态外观降级（单页、静态形态）。
